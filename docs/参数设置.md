  - 记号与单位
      - P_tx_dbm：发射端每 PRB 的等效全向辐射功率（EIRP，dBm）
      - L_fs_db：自由空间路径损耗（dB）
      - G_rx_db：接收端（含波束方向性）的增益（dB）
      - large_scale_db：大尺度衰落（含附加损耗与阴影，dB，可能为负）
      - f_GHz：载频（GHz），f_MHz = f_GHz × 1000
      - d_km：卫星至终端的斜距（km）
      - r_ground：地面水平距离（km）
      - alt_km：卫星高度（km）
      - θ_off：波束离轴角（deg）
      - hb：波束半功率角（deg）
      - Δ_edge：在半功率角处的相对衰减（dB，默认 3 dB）

  宽带接收功率（不含小尺度衰落）

  - 每个 UE 的宽带接收功率（dBm）:
      - P_rx_dbm = P_tx_dbm − L_fs_db + G_rx_db + large_scale_db
      - 代码参考：code/main.py:551

  路径损耗（FSPL）

  - L_fs_db = 32.45 + 20·log10(d_km) + 20·log10(f_MHz)
  - 代码参考：code/orbit.py:24-27

  几何关系与离轴角

  - r_ground = sqrt((Δx·cell_size_km)^2 + (Δy·cell_size_km)^2)
  - 斜距：d_km = sqrt(r_ground^2 + alt_km^2)
  - 离轴角：θ_off = arctan2(r_ground, alt_km)（度）
  - 仰角：elev = arctan2(alt_km, r_ground)（度）
  - 代码参考：code/orbit.py:60-68

  接收端波束增益（简化余弦模型）

  - 目标：在半功率角 hb 处衰减为 Δ_edge（dB）
  - 设 hb_rad = hb·π/180，target = 10^(−Δ_edge/10)，c = cos(hb_rad)
  - 指数 m = ln(target)/ln(c)
  - 模式功率比 patt(θ) = [cos(θ_rad)]^m，其中 θ_rad = θ_off·π/180
  - 接收增益：G_rx_db(θ_off) = G_boresight_db + 10·log10(patt(θ_off))
  - 代码参考：code/orbit.py:30-44

  大尺度衰落项 large_scale_db（3GPP NTN 三态）

  - 按仰角的逻辑斯蒂函数得到各态概率，抽样得到状态 S ∈ {los, slos, nlos}：
      - p_los = 1 / (1 + exp(−a_los·(elev − mid_los)))
      - p_nlos = 1 / (1 + exp(a_nlos·(elev − mid_nlos)))
      - p_slos = max(0, 1 − p_los − p_nlos)，随后归一化
  - 在状态 S 下：
      - large_scale_db = −additional_loss_db[S] + N(0, shadow_sigma_db[S])
  - 默认 K 因子（用于小尺度）：K_dB = {los: 12, slos: 6, nlos: −∞(瑞利)}，可被
    CONFIG.channel_params 覆盖
  - 代码参考：code/ntn_channel.py（概率与抽样：74-111、138-175；合成：176-215）

  每 PRB 接收功率（含小尺度衰落）

  - 对于每个 PRB，小尺度采用 Rician（单位平均功率）：
      - 若 K_lin = 10^(K_dB/10) > 0：
          - s = sqrt(K_lin/(K_lin+1))，σ = sqrt(1/(2·(K_lin+1)))
          - x ~ N(s, σ^2)，y ~ N(0, σ^2)，fading_lin = x^2 + y^2
      - 若 K=0（瑞利）：x,y ~ N(0, 1/2)，fading_lin = x^2 + y^2
  - 每 PRB 接收功率（dBm）：
      - P_rx_prb_dbm = P_rx_dbm + 10·log10(fading_lin)
  - 代码参考：code/main.py:559；Rician 采样：code/ntn_channel.py:112-137

  可选：PRB 级功率分配对接收功率的影响

  - equal_prb（默认）：各 PRB 的发射功率恒为 P_tx_dbm，P_rx_prb_dbm 不再额外缩放。
  - waterfill（可选）：总功率 P_tot_dbm（线性：P_tot_mW）在 PRB 或 UE 块间按水填充分配：
      - 以基准参考功率 P0_mW（由 P_ref_dbm，通常等于 P_tx_dbm）归一，定义每个资源的“单位功率
    SNR 增益” a_i（来自基准 SNR/功率比）
      - 解 p_i = clip(1/ν − 1/a_i, [p_min_mW, p_max_mW]) 使得 Σ p_i = P_tot_mW
      - 有效每 PRB 接收功率再增益：P_rx_prb_dbm_eff = P_rx_prb_dbm + 10·log10(p_i / P0_mW)
  - 代码参考：code/main.py（组水填充 1062-1158；PRB 水填充 1158-1260；缩放应用 1233-1260）

  参与参数清单（CONFIG 关键项）

  - 发射与链路预算
      - P_tx_dbm（默认 30.0 dBm，等功率模式下为每 PRB EIRP）
      - enable_geometry（是否按几何计算）
      - L_fs_db（禁用几何时的固定 FSPL，默认 154.0 dB）
      - G_rx_db（波束中心/终端合成增益，默认 38.0 dB）
      - sat_altitude_km、carrier_freq_GHz（默认 2.000）
      - beam_center_xy、cell_size_km（默认 0.063）、beam_half_bw_deg（默认 8.0）、
    beam_edge_drop_db（默认 3.0）
  - 信道（大/小尺度）
      - channel_model（默认 3gpp_ntn）、ntn_channel_profile（默认 s_band_handheld_urban）
      - channel_params（可覆盖 additional_loss_db、shadow_sigma_db、k_factor_db）
      - 逻辑斯蒂参数（见 code/ntn_channel.py：los_logistic、nlos_logistic）
  - 功率分配（可选）
      - dl_power_model（equal_prb | waterfill）
      - P_tot_dbm、p_min_dbm、p_max_dbm、P_ref_dbm（参考功率；调度阶段使用）

  备注

  - rx_nf_db、impl_loss_db 等只影响噪声项与 SNR，不参与接收功率 P_rx 的计算本身。
  - 若禁用几何（enable_geometry=False），L_fs_db 与 G_rx_db 直接取配置的常数；大尺度项仍按所选信道模型（或 lognormal）生成。
