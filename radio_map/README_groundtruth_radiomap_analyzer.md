# GroundTruth和RadioMap数据相似性分析工具

## 功能说明

这个脚本用于分析GroundTruth和RadioMap数据的相似性，提供全面的数据质量评估。主要功能包括：

1. **数据加载和预处理**: 自动加载npy和mat文件，统一单位和维度
2. **多种相似性指标**: 计算相关系数、误差指标、统计指标等
3. **可视化分析**: 生成散点图、差异分布图、3D切片图等
4. **详细报告**: 生成JSON和文本格式的分析报告

## 数据预处理

### 单位统一
- **GroundTruth**: W → dBm (公式: `P_dBm = 10 * log10(P_W * 1000)`)
- **RadioMap**: dBW → dBm (公式: `P_dBm = P_dBW + 30`)

### 维度统一
- 自动检测维度不匹配情况
- 支持维度重排: `(x,y,z) → (y,z,x)`
- 自动裁剪到公共形状

## 相似性指标

### 1. 相关系数
- **Pearson相关系数**: 线性相关性，范围[-1, 1]
- **Spearman相关系数**: 单调相关性，范围[-1, 1]

### 2. 回归指标
- **R²决定系数**: 解释方差比例，越接近1越好
- **MSE**: 均方误差，越小越好
- **RMSE**: 均方根误差，越小越好
- **MAE**: 平均绝对误差，越小越好

### 3. 统计指标
- **平均差异**: GT与RM的平均差异，越接近0越好
- **差异标准差**: 差异的离散程度，越小越好
- **数据范围比较**: 比较GT和RM的数据范围

## 使用方法

### 单文件分析

```bash
# 基本用法
python groundtruth_radiomap_analyzer.py GT_shanghai125.npy RM_shanghai125.mat

# 指定输出目录
python groundtruth_radiomap_analyzer.py GT_shanghai125.npy RM_shanghai125.mat -o analysis_results
```

## 评估标准

### 相关系数评估
- **优秀** (>0.9): 数据高度相关
- **良好** (0.7-0.9): 数据相关性较好
- **一般** (0.5-0.7): 数据相关性一般
- **较差** (<0.5): 数据相关性较低

### 误差评估
- **RMSE < 5 dBm**: 预测精度较高
- **RMSE 5-10 dBm**: 预测精度可接受
- **RMSE > 10 dBm**: 预测精度需要改进

## 环境要求

- Python 3.7+
- numpy
- scipy
- matplotlib
- h5py

## 文件格式支持

### GroundTruth文件
- **格式**: .npy (NumPy数组)
- **单位**: 瓦特(W)
- **维度**: 3D数组 (x, y, z)

### RadioMap文件
- **格式**: .mat (MATLAB文件)
- **单位**: 分贝瓦(dBW)
- **维度**: 3D数组 (y, z, x)
- **支持**: MATLAB v7.3和传统格式

## 故障排除

### 常见问题

1. **维度不匹配**
   - 脚本会自动尝试维度重排
   - 如果无法匹配，会裁剪到公共形状

2. **单位不统一**
   - 脚本会自动进行单位转换
   - 确保输入数据的单位正确

3. **数据质量问题**
   - 检查输入数据是否包含无效值
   - 脚本会自动过滤无效数据点

### 性能优化

- 对于大文件，建议分批处理
- 可视化生成可能需要较长时间
- 可以通过修改代码跳过某些可视化来加速
